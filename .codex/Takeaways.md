## Key Takeaways from codex

### Pros:
    - Tool is used best as an assistant, not just for coding but also for planning and other knowledge purposes
    - Constructs a good UI experience, although initially it does not account for different screen sizes
    - Boosts coding productivity and helps make decisions for coding design
    - Very guideful and resourceful
    - Can run multiple codex instances for coding, planning, designing, debugging, and asking basic questions
    - Can toggle between different modes and configure task & environment to deliver optimal output accordingly

### Cons:
    - Have to review the code given by codex, can't add the code automatically and implement functionalities
    - Powerful yet chaotic if speed is priority
    - Need to closely monitor, can't add code blindly and don't know what code it is writing
    - Need to give exact direction based on what you want through MCP, skills, agents, workflows, automations etc.
    - Need to spend time upfront setting up environment as it could give undesired output later in development
